# SmartLearn – Course Selling Platform

SmartLearn is a full-stack **MERN-based course selling platform** where users can explore courses, enroll in courses, and track their learning progress. The platform also provides an admin dashboard to manage courses and user enrollments.

## 🚀 Features

### 👨‍🎓 User Features

* User registration and login
* Browse and search available courses
* View course details and pricing
* Enroll in courses
* Submit transaction/UTR details
* View purchased courses
* Track course learning progress
* Access course videos and resources

### 👨‍💼 Admin Features

* Secure admin login
* Add, update, and delete courses
* Manage course categories
* View user enrollments
* Verify transaction details
* Approve or reject enrollments
* Generate enrollment reports in PDF format

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/Saniya-khatoon/Course_Selling_platfrom
cd SmartLearn
```

### Backend Setup

```bash
cd server
npm install
npm start
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```
